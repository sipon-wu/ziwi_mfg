## 4. 三个关键判断

### 4.1 它没有自适应，比 ECMS 更彻底

四档视口实测：

| 视口 | 侧栏宽 | 横向溢出 | `scrollWidth` vs `innerWidth` |
|---|---|---|---|
| 1440×900 | 176px | 否 | 1440 / 1440 |
| 1024×768 | 176px | 否 | 1024 / 1024 |
| 768×1024 | 176px | 否 | 768 / 768 |
| **414×896** | **176px** | **是** | **616 / 414（溢出 202px）** |

`document.styleSheets` 里**读不到任何 `@media (max-width|min-width)` 规则**。

> **结论：W/T/H 三档自适应，校宝一点参照价值都没有。**
> 这与 ECMS 的结论一致（ECMS 也是 0 断点）。两个外部参考站都不自适应，
> 说明"MES 车间多端"这件事只能按本项目自己的 UE 规格做，只能借视觉，不能借形态。

### 4.2 它值钱的是「数据密集型桌面后台」的信息组织方式

这恰好是 B3/B4 缺的那块，详见 §5。

### 4.3 它的视觉主线与本项目相反

| 维度 | 校宝 | 本项目（B1 之后） |
|---|---|---|
| 主色 | `#0066ff` 亮蓝 | `#0d7377` 墨绿（同 ECMS） |
| 侧栏 | 白色 176px | 深色 `#212529` 200px |
| 卡片圆角 | 16px | 10px |
| 卡片边框 | 无 | 1px `#e8eaed` |

## 5. 拍板结果与可借清单

> **Kane 拍板（2026-11-03）：跟 ECMS，只借校宝的交互组织。**
> 即：品牌色 / 侧栏 / 卡片维持 B1 已完成状态（与 ecms.ziwi.cn 品牌一致），
> 从校宝只搬**信息组织方式**，落到 B3/B4 的 **W 档**。

### 5.1 可借（逐条映射到批次）

| # | 校宝的做法 | 落到本项目 | 批次 |
|---|---|---|---|

### 5.2 明确不借

| # | 不借的东西 | 原因 |
|---|---|---|
| **N1** | 表格行高 43px | 低于本项目触屏底线（裸手 48 / 手套 56），手套车间必误触 |
| **N2** | 0 断点、固定 176px 侧栏 | 414 宽溢出 202px，与"车间全触屏"前提直接矛盾 |
| **N3** | 卡片圆角 16px、无边框 | 与 ECMS `.section`（10px + 1px `#e8eaed` 边框）冲突，会破坏品牌一致性 |
| **N4** | 亮蓝 `#0066ff` 主色 | 与知微品牌墨绿 `#0d7377` 冲突 |
| **N5** | 顶部三系统切换条 | 本项目的同类需求已由「能碳跳转 `ecms.ziwi.cn`」这种方式解决，不再做站内切换 |
