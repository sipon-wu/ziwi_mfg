# 知微 ziwi 全场景穷举清单（v1 · 2026-10-29）

> 目的：用穷举场景的方式，把功能细节与边界条件暴露出来，作为 Beta 打磨的输入。
> 编号规则：`模块前缀-类型+序号`。类型：**S** 主流程 / **E** 异常 / **B** 边界 / **X** 跨模块联动。
> 现状标记：✅ 已通（本轮/上轮已验证）｜⚠️ 部分（功能在但流程未闭环）｜❌ 缺失｜❓ 待验证
